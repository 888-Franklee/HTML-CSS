
# CSSの `text-align` プロパティについて

## 1.  概要

`text-align` プロパティは、**インラインコンテンツ（主にテキスト）を水平方向に整列させる**ために使用されます。
これは、ブロック要素内のテキストやインライン要素の配置に影響を与えます。

---

## 2. 基本構文

```css
selector {
  text-align: 値;
}
```

---

## 3. 主な値

| 値 | 意味 | 説明 |
|----|------|------|
| `left` | 左揃え | テキストを左端に揃えます（デフォルト、LTR言語向け） |
| `right` | 右揃え | テキストを右端に揃えます（RTL言語向けなど） |
| `center` | 中央揃え | テキストを中央に配置します |
| `justify` | 両端揃え | 各行のテキスト幅を均等にして、左右両端を揃えます |
| `start` | 開始位置揃え | 書字方向の先頭に揃えます（例：LTRならleft） |
| `end` | 終了位置揃え | 書字方向の終わりに揃えます（例：LTRならright） |

---

## 4. 使用例

```html
<div style="text-align: left;">これは左揃えです。</div>
<div style="text-align: center;">これは中央揃えです。</div>
<div style="text-align: right;">これは右揃えです。</div>
<div style="text-align: justify;">
  これは両端揃えのテキストです。行の幅を揃えるために、単語の間隔が自動的に調整されます。
</div>
```

---

## 5. 注意点

- `text-align` は**親要素**に指定することで、その中の**インラインコンテンツ**に効果があります。
- `justify` を使用すると、読みやすさが向上する場合がありますが、短い文には不向きです。
- `start` や `end` は、柔軟なレイアウト（特に多言語対応）に役立ちます。

---

## 6. 補足：ブロック要素の中央揃えとの違い

テキストではなく、**ブロック要素自体を中央に配置したい場合**は、以下のように `margin` を使います：

```css
div {
  width: 200px;
  margin: 0 auto; /* 要素を中央に配置 */
}
```
