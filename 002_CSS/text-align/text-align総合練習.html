text-align 総合練習

左揃え:
これは左に揃えられた段落です。すべてのテキストは左端から開始されます。
中央揃え:
このテキストは中央に配置されています。見出しやタイトルなどによく使われます。
右揃え:
テキストが右側に揃えられています。右から読む言語や、特定の装飾的目的に使われます。
両端揃え（justify）:
この段落は両端揃えで表示されています。各行のテキストが左右の端に揃うように調整され、読みやすさを高めます。
start 揃え（LTR）:
書字方向が左から右（LTR）の場合、「start」は左揃えと同じになります。
end 揃え（RTL）:
書字方向が右から左（RTL）の場合、「end」は右揃えと同じになります。
