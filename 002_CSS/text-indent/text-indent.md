
# CSS `text-indent` の紹介（日本語）

## 1. 概要

`text-indent` は、段落の最初の行の字下げ（インデント）を指定するための CSS プロパティです。主に文章を読みやすく整えるために使用されます。

## 2. 書き方（構文）

```css
selector {
  text-indent: 値;
}
```

## 3. 使用例

```html
<style>
  p {
    text-indent: 2em;
  }
</style>

<p>これは段落の最初の行だけが字下げされる例です。</p>
```

## 4. 使用時の注意点

- インデントは**最初の行**のみに影響します。
- `text-align: justify;` と併用可能。

## 5. 負の値の例

```css
p {
  text-indent: -1em;
}
```

## 6. 応用：画像と組み合わせたスクリーンリーダー対応

```css
p {
  text-indent: -9999px;
}
```

## 7. まとめ

| プロパティ名 | 説明 |
|--------------|------|
| `text-indent` | 段落の最初の行の字下げを指定する |

## 8. よく使う値

| 値        | 意味                            |
|-----------|---------------------------------|
| `0`       | 字下げなし                      |
| `2em`     | 2文字分字下げ（フォントに依存） |
| `20px`    | ピクセル指定の字下げ            |
| `-1em`    | ネガティブインデント（左にはみ出す） |

## 9. 実用ヒント

- 日本語の段落では `1em`〜`2em` が自然
