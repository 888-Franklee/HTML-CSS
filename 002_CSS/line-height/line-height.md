
# CSS `line-height` の紹介（日本語）

## 1.  概要

`line-height` は、テキストの行間（行と行の間の高さ）を指定する CSS プロパティです。テキストの可読性や見た目を整えるために使用されます。

---

## 2.  書き方（構文）

```css
selector {
  line-height: 値;
}
```

- `値` には以下のような指定が可能です：
  - 単位なしの数値（例：`1.5`）
  - 長さ（例：`24px`、`1.2em`）
  - パーセンテージ（例：`150%`）
  - `normal`（初期値）

---

## 3.  使用例

```html
<style>
  p {
    line-height: 1.6;
  }
</style>

<p>この段落は行間が「1.6」に設定されています。読みやすくなる効果があります。</p>
```

---

## 4.  単位なし vs 単位あり

- `1.5` のような **単位なしの数値** は、要素の `font-size` に対する倍率です。
- `24px` のような **単位あり** の場合、絶対的な高さになります。

---

## 5.  よく使う値

| 値         | 説明                                  |
|------------|---------------------------------------|
| `normal`   | ブラウザの標準的な行間（約1.2〜1.4）  |
| `1.5`      | フォントサイズの1.5倍の行間           |
| `24px`     | 固定の高さで行間を指定                |
| `150%`     | フォントサイズの150%で行間を指定      |

---

## 6.  使用時の注意点

- 複数行のテキストに特に効果があります。
- 親要素に `line-height` を指定すると、子要素にも継承されます。
- 可読性向上のためには `1.4〜1.8` 程度が推奨されます。

---

## 7.  応用例：リストやナビゲーションで

```css
nav li {
  line-height: 2;
}
```

リスト項目間の間隔を広げて、視認性を上げることができます。

---

## 8.  まとめ

| プロパティ名 | 説明                     |
|--------------|--------------------------|
| `line-height` | テキストの行間の高さを指定する |
