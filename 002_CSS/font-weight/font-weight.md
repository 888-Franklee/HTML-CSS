
# CSSの `font-weight` プロパティ解説

## **1. `font-weight` とは？**

`font-weight` プロパティは、HTML要素の**文字の太さを指定するためのCSSプロパティ**です。  
テキストの強調やデザイン性を高めるために使用されます。

---

## **2. 基本構文**

```css
selector {
  font-weight: 値;
}
```

---

## **3. 値の指定方法**

### **3.1 キーワードで指定**

```css
p {
  font-weight: bold;
}
```

- `normal`：標準の太さ（400に相当）
- `bold`：太字（700に相当）
- `bolder`：親要素よりも太く
- `lighter`：親要素よりも細く

---

### **3.2 数値で指定**

```css
p {
  font-weight: 600;
}
```

- **100～900** の範囲で指定（100刻み）
- 値が大きいほど文字が太くなります。
- 通常は `400` が標準、`700` が太字です。

例：

```css
p {
  font-weight: 100; /* 非常に細い */
}

strong {
  font-weight: 900; /* 非常に太い */
}
```

---

## **4. 注意点**

- 使用するフォントによっては、すべての太さがサポートされていない場合があります。
- ウェブフォント（Google Fonts など）を使うと、複数の太さを指定できることが多いです。

---

## **5. 実例**

```css
body {
  font-weight: normal; /* 400 */
}

h1 {
  font-weight: bold; /* 700 */
}

p.light {
  font-weight: 300;
}
```

---

## **6. ポイント**

- 太字は `font-weight: bold;` または `700` が基本。
- デザインに合わせて細字（300）や極太字（900）を使うと見た目が整いやすい。
- Webフォントの読み込み時は、必要な太さをあらかじめ指定しておくとよい。
