
# CSSの `font-size` プロパティ解説

## **1. `font-size` とは？**

`font-size` プロパティは、HTML要素の**文字の大きさを指定するためのCSSプロパティ**です。  
テキストの読みやすさやデザインの一貫性を保つために使用されます。

---

## **2. 基本構文**

```css
selector {
  font-size: 値;
}
```

---

## **3. 値の指定方法**

`font-size` には様々な指定方法があります。

### **3.1 絶対値 (px, pt など)**

```css
p {
  font-size: 16px;
}
```

- **px (ピクセル)** が最も一般的です。
- デバイスの解像度に依存しますが、見た目が安定します。

---

### **3.2 相対値 (em, rem, %)**

```css
p {
  font-size: 1.2em;
}
```

- **em**: 親要素のフォントサイズに対して相対的に決まります。
- **rem**: ルート要素（`html`）のフォントサイズに対して相対的に決まります。
- **%**: 親要素のフォントサイズに対する割合で指定します。

例：

```css
html {
  font-size: 16px;
}

p {
  font-size: 125%; /* 16px × 1.25 = 20px */
}
```

---

### **3.3 キーワード**

```css
p {
  font-size: large;
}
```

- `xx-small`, `x-small`, `small`, `medium`, `large`, `x-large`, `xx-large` などのキーワードを使ってサイズを指定できます。
- 相対的な大きさでブラウザにより微調整されます。

---

### **3.4 相対キーワード**

```css
p {
  font-size: larger;
}
```

- `larger`: 親要素より大きく
- `smaller`: 親要素より小さく

---

## **4. 実例**

```css
body {
  font-size: 16px;
}

h1 {
  font-size: 2rem; /* 16px × 2 = 32px */
}

p {
  font-size: 1em; /* 親要素のフォントサイズを基準 */
}
```

---

## **5. ポイント**

- 一般的に `rem` を使うとデザイン全体のサイズ調整がしやすくなります。
- `em` はネストが深くなるとサイズが意図せず大きくなることがあるので注意。
- ユーザーのブラウザ設定（ズームや標準フォントサイズ）に対応するため、相対値を活用するのが推奨されます。
